نَماء | Nama'a 🌱
نظام ذكي وشامل لمراقبة ورعاية النباتات باستخدام تقنيات إنترنت الأشياء (IoT).
💡 فكرة المشروع
"نَماء" ليس مجرد تطبيق لمراقبة الرطوبة، بل هو نظام متكامل يهدف إلى تسهيل رعاية النباتات وضمان نموها في بيئة مثالية. يقوم النظام بمراقبة مستمرة لظروف البيئة المحيطة بالنبات وتوفير بيانات لحظية للمستخدم مع إمكانية التدخل الآلي (الري الذاتي) لضمان عدم تأثر النبات بالظروف القاسية.
المميزات التقنية 
• لوحة تحكم تفاعلية (Dashboard): عرض حي لدرجات الحرارة، رطوبة التربة، ورطوبة الجو باستخدام عدادات (Gauges) بصرية جذابة.
• نظام تنبيهات ذكي: إرسال تحذيرات فورية للمستخدم في حال انخفاض مستوى رطوبة التربة (أقل من 35%) لضمان سرعة الاستجابة.
• تعدد طرق الاتصال: يدعم التطبيق ثلاثة أنظمة اتصال مختلفة تم برمجتها بعناية:
1. WiFi: للاتصال المباشر عبر الشبكة المحلية.
2. Cloud Firebase: لمراقبة النبات عن بُعد من أي مكان في العالم.
3. Bluetooth (BLE): للتحكم والاتصال القريب الموفر للطاقة.
• واجهة مستخدم عصرية: تصميم متجاوب (Responsive) مستوحى من ألوان الطبيعة مع تجربة مستخدم سلسة تتضمن شاشات ترحيب وتسجيل دخول.
🛠️ التقنيات المستخدمة
• اللغات: HTML5, CSS3, JavaScript
